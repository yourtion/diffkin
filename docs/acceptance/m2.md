# M2 候选验收记录

日期：2026-10-28。版本：0.1.0-alpha.1。许可证：MIT。

**结论：M0–M2 核心功能已实现，以下自动化技术验收通过。完整 M2 产品退出条件仍有待验收项，因此当前保持 Alpha 候选，不标记为稳定版或全部里程碑验收完成。**

## 已交付

- 冻结 Git 对象、index 和原始工作区内容，支持四种比较模式、分页文件清单和显式异常状态。
- 桌面与 CLI 共用读取/比较用例；普通打开不改 index/ref，不执行仓库脚本、Git filters、hooks、外部 diff 或对象拉取。
- 只读双栏/统一 diff、未改行折叠、搜索、选择、精确源码复制、文件筛选和键盘导航。
- JS/TS/TSX 保守格式证明、唯一顶层函数移动、简单参数/let/const 改名、内部修改对照；Vue script 复用及原始 SFC 坐标。
- 格式证明可以实际收起并恢复。统一视图的旧侧删除块只有在整个 chunk 双侧均属于同一格式证明时才收起；混合真实修改的块保守保留。
- 当前关系的双侧定位与局部比较。关系通过配对面板、行号与证据呈现；没有绘制额外跨栏曲线。
- 排队与运行中的取消、工作预算、迟到结果隔离、有界缓存。审查记录绑定快照、源码身份及协议/规则版本；最近仓库与审查状态保存在本地 WebView 存储，尚未引入 SQLite。
- 三平台检查、四目标打包、Release 草稿、版本/产物校验、MIT 与第三方许可材料。

| 浏览器 UI              | 11/11 回归通过                                | 搜索/布局/格式展开、元数据、取消/迟到结果、分页竞态、审查依据失效 |
| 真实结果逐文件 UI 流程 | 3/3 项目通过                                  | 58 个变化文件全部可选择、显示、标记审查，未发生前端报错           |

浏览器测试使用真实 React/CodeMirror 与模拟 IPC；真实项目数据由 Rust CLI 从 Git 捕获。两者分别验证读取/分析和界面，**不等同于已完成系统 WebView → 原生 IPC 全链路验收**。测试中自动标记“已审查”只用于验证 UI 状态，也不代表完成了这些上游项目的业务代码审查。

结构案例属于本项目回归集，未获得独立人员审校；其标签级结果不能当作任意项目的泛化准确率。[详细结构报告](structure.md)包含支持域、首次暴露的问题、修复与测量范围。

## 性能观察

参考开发机为 Apple M2 / 16 GiB / macOS 27.2。各场景 30 次，均为 release、暖进程/热文件系统；开发机存在并发任务，不是隔离实验室测试。

| 测量边界                              | p95       | 原始记录                                      |
| ------------------------------------- | --------- | --------------------------------------------- |
| 10k tracked / 100 changed，两提交快照 | 100.42 ms | [快照原始样本](snapshot-benchmark.json)       |
| 同规模 HEAD → 工作区快照              | 428.07 ms | [快照原始样本](snapshot-benchmark.json)       |
| 1,000 函数、单处条件变化，纯分析      | 21.614 ms | [内核原始样本](results/kernel-benchmark.json) |
| 活跃解析取消 → 线程退出               | 0.495 ms  | [内核原始样本](results/kernel-benchmark.json) |

这些值没有包含 IPC/渲染。不能据此宣称冷启动、完整首屏、滚动、总进程内存或空闲 CPU 已达到 `quality.md` 门槛。

## 版本与构建

初始框架 main 的[三平台 CI](https://github.com/yourtion/diffkin/actions/runs/40632863823)已通过。alpha.0 首次发版构建成功产出四目标安装包，但 Windows CLI 归档遇到盘符被 tar 当成远端的问题；alpha.1 改用相对路径归档，并加入真实 tar 内容回归。

本候选本机 `pnpm check/build`、协议漂移检查、Rust fmt/Clippy/workspace tests 均通过。前端构建为 733.6 kB（gzip 242.1 kB）。macOS ARM DMG 3.22 MiB、应用 16.01 MiB、CLI 压缩包 904 KiB；镜像校验与只读挂载通过，镜像内版本、MIT 和 438 项依赖许可材料已核对，CLI 解压后版本与结构 JSON 可运行。SHA256 与精确字节数见 [打包记录](results/macos-alpha1-packaging.json)。仅有 linker ad-hoc 签名，尚无 Developer ID 签名/公证。

alpha.1 的[三平台 CI](https://github.com/yourtion/diffkin/actions/runs/40636675875)与[四目标发版](https://github.com/yourtion/diffkin/actions/runs/40636697263)均已通过。[Release 草稿](https://github.com/yourtion/diffkin/releases/tag/untagged-350ca02eca251783a832)包含 9 个产物及 SHA256SUMS；四份 CLI 下载后独立校验哈希与归档中 MIT/第三方材料，Mac ARM CLI 实际执行版本检查通过。所有 Release 默认只生成草稿，不自动公开发行。

## 尚待完成的产品门槛

- 原生 macOS 安装、实际 WebView/IPC 操作、退出重开及卸载体验。当前自动化宿主锁屏，用户明确选择暂缓并记录待验收；不能用浏览器测试替代。
- Windows/Linux 的真实安装与交互，正式签名/公证。编译与打包成功只证明构建链路。
- 整应用冷启动、首个可见结果、滚动帧耗时、全部进程内存和空闲 CPU 的 30 次/规定时长测量。
- 至少 5 名外部试用者的可复现反馈，以及独立人员对正确性 fixture 的审校。
- 受支持实体域的独立保留集精确率/召回率测量；不能把固定回归集的零误报直接替代这个门槛。

这些事项保留为未完成；M3–M7 未开始。按用户最新顺序，先补齐格式证明、移动连线、改名分组和 Python/Java/Go/Rust 多语言能力，再继续 M3/M4；原生验收按用户要求暂缓，不以浏览器结果替代。
