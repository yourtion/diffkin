# 核心 diff：语言能力与验收边界

本轮在原有 M2 功能候选之上扩展核心比较。此文只记录当前实现和可定位的测试，不把 grammar 已安装、语法高亮可用或某个演示成功等同于整种语言完成语义支持。本轮候选版本为 `0.1.0-alpha.2`，分析规则为 `syntax-v2`。

## 能力矩阵

表中“格式”均指有原始范围和规则证据的保守折叠。“移动”指同一文件、同一声明容器内唯一可配对实体的相对顺序变化；不表示行为等价。“改名”始终保持可见，仅用于声明及引用归组，不自动修改源码。

| 语言                | 语法格式比较                                                                                              | 作用域内移动                                                                            | 局部改名归组                                                                             | 界面高亮                                                      |
| ------------------- | --------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| JS / TS / JSX / TSX | 完整 CST 与原始 token 核对；白名单标量表达式的冗余括号可归一；语义敏感换行、注释、模板和 JSX 区域保守保留 | 命名函数声明、绑定到简单变量名的箭头/函数表达式、类中的命名方法；区分容器和方法修饰身份 | 简单参数和函数体一级 `let` / `const`；声明和所有引用必须对应，未知绑定回退               | 按扩展名选择 JS / TS 与 JSX 模式                              |
| Python              | 空格排版与白名单标量括号；块归属必须保持一致，缩进含非空格空白（如 tab、form feed）时不产生格式折叠       | 模块中的命名函数、同一类容器中的方法；不进入函数内部搜寻嵌套函数                        | 模块函数的简单参数、带类型的简单参数、函数体一级简单赋值；可配对同一局部变量的后续重赋值 | `.py` / `.pyi` / `.pyw`；其中 `.pyw` 当前仅高亮和原始文本比较 |
| Java                | CST 与原始 token 核对；有限标量括号规则；cast、文本块和注释保持其原始事实                                 | 类/接口等声明容器中的方法与构造器；方法参数类型纳入身份，区分可唯一配对的重载           | 非重载方法中的简单参数和函数体一级局部变量声明；成员访问及复杂作用域回退                 | `.java`                                                       |
| Go                  | CST 与原始 token 核对；有限标量括号规则；自动分号相关换行、字符串和 rune 原文保留                         | 文件内函数和带接收者类型身份的方法；不跨文件或推断接口实现关系                          | 普通函数的简单命名参数、函数体一级 `var` 声明；不确认 `:=` 或 receiver 方法中的改名      | `.go`                                                         |
| Rust                | CST 与原始 token 核对；有限标量括号规则；宏 token、属性、字符串和字符原文保留                             | 文件、内联 `mod`、`impl`、`trait` 声明容器中的有函数体项；不读取外部模块文件            | 简单参数和函数体一级 `let` 标识符；模式、shadowing、宏和闭包回退                         | `.rs`                                                         |
| Vue SFC             | script 内容按 JS / TS / JSX / TSX 分析，并映射回 SFC 原始字节/UTF-16 坐标；template/style/块属性保持文本  | 支持的 script 中复用上述实体规则；不跨 script 块或 template 建立移动关系                | 支持的 script 内复用 JS / TS 规则；不推断 `script setup` 暴露名称与模板绑定的联动改名    | 整个 SFC 使用 Vue 高亮；聚焦 script 关系时使用代码高亮        |

Python class 方法可以显示结构移动，但类作用域的局部改名仍回退。Java 重载方法可以按参数类型区分移动身份，但重载范围的局部改名不因此自动获得确认。Go receiver 方法、Rust 含 `self` 的方法同样不能用“移动可配对”推导出“局部改名已支持”。

## 格式降噪如何保持可审查

比较首先生成可重建双侧原始文本的 raw diff。格式证明还要检查完整语法形状、关键 token、敏感区域和覆盖范围；存在条件、常量、调用等真实编辑时保留相应变化。可以在同一文件内折叠独立的纯格式子区域，而不折叠邻近的真实修改。

括号归一限于明确支持的标量表达式；不会通用地删除所有括号。元组、cast、生成器、lambda、walrus、可选链边界、指令字符串、宏 token 及未知语法不能借此取得格式证明。解析失败、预算耗尽、覆盖不合法时回到可见的原始编辑。

局部格式区域必须具有可对应的子树和完整原始行范围，不能因为一行中的部分表达式未改变，就把该行的其他编辑一起隐藏。保留的原文仍可搜索、复制，并可通过“完整原始视图”展开。

## 局部改名的确认域

四种新增语言使用独立的声明/引用检查。候选声明的角色及位置需要对应，候选绑定的每个引用均需在另一侧找到相同语法角色和位置；简单括号包装不会机械地破坏对应，但 cast、元组等其他结构不透明化。声明或引用增删、引用换位、旧名字与新名字相互覆盖、初始化前可能读取外层变量等情况均回退。

候选名字若也出现在属性名、类型名、方法名或外层自由引用中，当前实现保守拒绝确认。比如 `obj.count + count` 改为 `obj.amount + amount` 不会只显示一个局部改名；即使属性 `obj.count` 保持不变，也不会把它误算为参数 `count` 的引用。

| 语言    | 明确不确认的绑定区域                                                                                                                                             |
| ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| JS / TS | 嵌套 callable / block、`var`、解构、属性简写、动态 `eval` / `arguments`、复杂声明与类型作用域；新增括号若改变现有引用路径，可保守回退                            |
| Python  | class、嵌套函数、lambda、global/nonlocal、comprehension、import、for/with/except/match 绑定、解包/属性赋值、默认参数和 splat、动态 locals/globals/vars/eval/exec |
| Java    | 重载方法、成员/`this`/`super` 访问、匿名类、lambda、嵌套块、循环/catch/pattern/resource 绑定、receiver/varargs 参数和泛型绑定区域                                |
| Go      | `:=`（包括合法的部分重声明）、receiver 方法、named/multiple result 列表、闭包、嵌套块、range/switch/select 相关绑定、局部 const/type、复合字面量                 |
| Rust    | closure、macro、nested block、`self` 参数、tuple/struct 等 pattern、重复 `let` shadowing、loop/match/let-condition、局部类型/常量项和泛型绑定区域                |

改名归组不证明调用者兼容性。Python keyword 参数、Java 调用解析、公开名称或运行时反射等影响仍需人工检查。移动/改名与条件编辑同时出现时，父变更组保留相应标签，条件修改作为独立内部编辑保留可见。

## 移动与展示边界

移动依据来自同一声明容器中唯一身份及相对顺序的变化。前方新增内容导致的行号平移不算移动；重复身份、重复容器、复制仍保留原位置、跨文件和跨作用域迁移不作唯一移动确认。等长的最少移动方案可能不唯一，证据中保留这一限制。

当前界面支持按父子关系组织事件，选择移动项后对照其双侧内容，并突出当前关系。文件名决定高亮语言；高亮独立于内核的规则证明。未知语言继续提供原始文本比较，不能因为编辑器有颜色就显示结构或绑定已经分析。

Vue 要求可完整解析的 script 块；普通 script 与 setup 模式分别唯一，支持 `js/ts/jsx/tsx`。`src` 外部脚本不加载，未知预处理器、重复模式、块集合变化或解析不完整时明确回退；script 块头属性发生变化的部分也保留原始文本，不借用旧块的结构证明。
