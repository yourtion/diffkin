# 结构分析验收语料

`cases.json` 保存 105 个明确指定输入和预期的案例，不由待测算法生成期望值。它是随实现维护的工程回归集；仍需要产品负责人/外部审校，不能称为独立盲测或 5 位用户试用。

覆盖 28 个格式阳性、6 个移动阳性、11 个局部改名阳性，以及条件编辑、ASI、可选链、字符串/模板/正则/JSX、指令注释、BOM、重复函数、复制、遮蔽、捕获、eval、解构、属性简写、自由变量冲突、引用增删、Vue 块属性/外部脚本/未知预处理器、解析错误等反例。每个案例都验证原始字节重建、覆盖项唯一性、有效原始坐标和必须可见的编辑。

```sh
cargo test -p diffkin-analysis --test structure -- --nocapture
cargo run -p diffkin-analysis --example benchmark --release
```

额外测试验证 300 组 Unicode/CRLF/NUL 组合的字节重建、逐字符边界的 UTF-16 映射、单次移动不误标所有平移邻居、解析中取消释放以及 Vue 重复 script 的回退。

## 支持范围

- JS/TS/TSX 采用完整 CST 形状与原始 token 核对。字符串、模板、正则等文本节点完整保留。带注释、模板、JSX 的区域不自动折叠；分号、括号不归一化。
- 文件内移动仅确认唯一名字的顶层函数声明，以最长不变锚点序列求最少重新定位。等长最优方案可能不唯一，事件给出此限制；移动不是行为等价证明。
- 局部改名仅覆盖函数简单参数与函数体一级 `let`/`const`。声明和所有引用的语法路径必须对应。嵌套作用域、动态查找、解构、属性简写、`var`、引用增删、自由变量碰撞均拒绝确认。改名及内部修改始终保留可见。
- Vue 用 HTML grammar 确定原始 script 范围，复用 JS/TS 分析；模板/样式和块属性始终为原始文本。`src`、未知 lang、重复 script 模式、解析不完整时回退。
- 200,000 字节 / 5,000 行以内运行结构分析；更大输入由应用层提供大文件摘要与分段原文。结构阶段有 1 秒预算及 100,000 语法节点限额，取消/错误不能留下格式证明。

`benchmark` 输出每个场景 30 次原始样本与 p50/p95/max，仅测 Rust 内核、进程内暖运行，不包含 Git、IPC、WebView、内存、冷启动或用户操作延迟。
